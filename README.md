# B&M DualCore

Página de soporte TI de **Matias Bardales** y **Jesús Mendoza**.

**B&M DualCore** junta lo serio de una firma (Bardales & Mendoza) con lo memorable de dos técnicos trabajando en paralelo: doble núcleo, un solo soporte.

## Qué incluye

- Sitio interactivo para desktop y móvil
- Diagnóstico DualCore en 3 pasos
- Servicios: PCs, laptops, cámaras, software, ensamblaje, redes y mantenimiento
- Formulario que arma el mensaje de WhatsApp
- Presentación de ambos fundadores

## Cómo verla

Abre `index.html` en el navegador, o desde la carpeta del proyecto:

```bash
npx serve .
```

## Datos para personalizar

En `js/main.js` cambia el número de WhatsApp:

```js
whatsapp: "51999999999"
```

En `index.html` actualiza el correo y el teléfono visibles en contacto.
